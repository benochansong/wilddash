# WILD DASH 3D RC3 — Gameplay Upgrade

Version: **0.9.0-rc3**

RC3 integrates the expanded Grand Prix, ordered checkpoints, six-item party racing, character skills, AI skill/item decisions, and the Chimera gameplay build system into the four-round campaign.

## Grand Prix

- 17 route points, approximately 1.48 km
- 7 ordered checkpoints with high-speed tunneling assistance
- Meadow straight, bends, forest run, uphill/jump approach, narrow bridge, obstacle field, S-curves, hairpin, tunnel, downhill rush, split route, risky shortcut, merge and final chicane/straight
- 7 item stations × 3 lanes = 21 Item Boxes
- Risky shortcut saves about 80 m versus the safe detour, but is narrow and contains a rotating sweeper
- Rabbit AI can deliberately choose the shortcut route

## Items

1. DASH BERRY
2. BUBBLE SHIELD
3. STICKY FRUIT
4. SHOCKWAVE
5. ROCKET NUT
6. RECOVERY FEATHER

Items are pickup/consumption based. Character Skills remain a separate cooldown system.

## Character Skills

- Dog — RALLY DASH: stable acceleration/handling burst
- Rabbit — SPRING LEAP: high forward leap for obstacle/shortcut play
- Elephant — STAMPEDE: capped push attack with knockback resistance
- Cat — SHADOW STEP: directional quick dash with brief racer-collision evasion

Keyboard: **E Skill / Q Item**  
Gamepad: **X Skill / B Item**

## Chimera Gameplay Build

- HEAD → exact Active Skill of source animal
- BODY → restrained Passive Trait (up to ~10%)
- TAIL → smaller Utility Bonus (up to ~7%)

Chimera builds are intended as trade-off builds, not strict upgrades over the four base characters.

## Campaign

Grand Prix → Fruit Collection → Floor Collapse → Push Out

## Release Candidate Notes

- Windows x64, offline single player
- Save format remains v2 and includes Chimera/loadout data plus settings/profile data
- Keyboard rebinding, gamepad defaults, pause, audio/graphics/accessibility settings are included
- Windows executable is currently unsigned; Windows SmartScreen may warn on first launch
- 10 racers is the normal campaign ceiling; 25/50 racer runs are scalability benchmarks, not normal race settings
