# Manual Character Select checklist

- Open the active Character Select used by `GameManager`.
- At 1600x900, click all 12 racers and confirm the right ability card updates immediately.
- Confirm exact 0-10 values for Swim, Climb, Agility, Power, Rough, Defense.
- Resize the window and verify the right card remains attached to the right UI region without severe overlap.
- Enter Chimera mode and verify the body-based stats card remains readable.
- Run Round 1, Fruit Frenzy, Push-Out, and Snowpeak to check for regressions.
